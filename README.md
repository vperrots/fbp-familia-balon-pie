# FBP – Familia del Balón Pie

Sitio web oficial de **FBP – Familia del Balón Pie**, academia de fútbol femenino en Chicureo, Santiago de Chile.

## Primera versión
- Sitio responsive para celular y computador.
- Información de academia, entrenamientos y planes.
- Formulario de clase de prueba conectado a WhatsApp.
- Enlaces a Instagram y ubicación.
- Preparado para incorporar logo y fotografías reales.
